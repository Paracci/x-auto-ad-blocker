Automatically blocks advertisers on X and lets you download videos, GIFs and images — all client-side, no data collected.

How it works

• Detects ad labels (Ad, Promoted, Reklam) via MutationObserver

• Silently clicks Block → Confirm in the background

• Uses X's Syndication API to fetch the highest-bitrate MP4

Privacy

No data is collected or transmitted. The only external request is to cdn.syndication.twimg.com — X's own public API — and only when you click the download button.
